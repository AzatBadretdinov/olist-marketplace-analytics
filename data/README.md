# Исходные данные

Источник: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).
Автор данных: Olist. На странице источника указана лицензия CC BY-NC-SA 4.0.
CSV в Git не включаются. Скачай девять файлов с исходной страницы и распакуй прямо в data/.

Файлы:
- olist_customers_dataset.csv
- olist_orders_dataset.csv
- olist_order_items_dataset.csv
- olist_order_payments_dataset.csv
- olist_order_reviews_dataset.csv
- olist_products_dataset.csv
- olist_sellers_dataset.csv
- olist_geolocation_dataset.csv
- product_category_name_translation.csv

reports/source_manifest.json содержит SHA-256 локальных файлов, использованных в отчёте.
Размеры и результаты относятся именно к этим файлам; другие версии могут отличаться.
